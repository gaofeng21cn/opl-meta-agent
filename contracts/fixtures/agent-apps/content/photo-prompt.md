# Review a Photo Steward plan

Read the exact selected plan through photo.steward.v1#plan.exact. Preserve plan_id,
plan_dir, plan_revision and the existing owner receipt. Read the current task's
bound photo handling policy, then use owner-collaboration to present the shared
plan difference and record the user's decision. A missing optional presentation
preference does not block review; a missing required handling policy blocks apply.

Apply only a confirmed plan through photo.steward.v1#plan.apply with its exact
plan_dir, plan_revision and request_id. Revalidate action-critical knowledge first.
Inspect the same plan/receipt after dispatch and report applied only when the
Photo owner confirms it. Unknown and stale outcomes remain explicit. Preserve the
existing task and library owner; do not create a second plan or photo database.
